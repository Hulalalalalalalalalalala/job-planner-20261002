Install
python3 --version
Python 3.10 or newer; no third-party dependencies.

Start
python3 job_planner.py samples/plan.json
Reports completed 3 and failed 0; saves .results/latest.json.

Dependencies
python3 job_planner.py samples/plan-dependencies.json --output .results/deps.json
Reports completed 1, failed 1 and blocked 2 (exit 1): the failing branch blocks
its downstream chain while the independent CSV summary still succeeds; forward
references run in the earliest-ready plan order.

Partial runs
python3 job_planner.py samples/plan-dependencies.json --only joined-checksum
Runs only the named job plus its prerequisites; repeat --only to select several
targets. Unknown, blank or repeated names exit 2 with an error JSON.

Preview
python3 job_planner.py samples/plan-dependencies.json --preview --only joined-checksum
Prints the jobs that would run, in run order, with depends_on, reason
(target/prerequisite, or all without --only) and required_by; exits 0 and runs
nothing. The whole plan is still validated; failures exit 2 with an error JSON.

Retry preview
python3 job_planner.py samples/plan-dependencies.json --retry-preview .results/deps.json --output .results/deps.json
Reads the named report and prints {"targets": [...], "jobs": [...]}: targets are
the report's failed/blocked tasks in plan order and jobs cover them plus every
prerequisite (shared once), in run order, with the same fields as --preview.
Reports may be partial and report may equal --output. Empty results or no
failures print {"targets": [], "jobs": []}. Nothing runs or is written; a bad,
missing or escaping report path exits 2 with an error JSON. Cannot combine with
--preview or --only.

Retry
python3 job_planner.py samples/plan-dependencies.json --retry .results/deps.json --output .results/deps.json
Executes the same targets and scope the preview would show: failed/blocked
tasks plus every prerequisite (even ones that completed before, shared once);
unrecorded tasks join only when required and unrelated branches never run.
Ordering, failures and blocked_by follow a normal run, judged on this run's
results only. The report at --output holds just this run's records; report may
equal --output (targets use the pre-overwrite content). No targets prints
{"completed":0,"failed":0}, exits 0 and touches no files. Bad reports and
plans exit 2 with an error JSON; output write failures exit 2 without undoing
finished tasks. Cannot combine with --only, --preview or --retry-preview.

Smoke Test
python3 -B -m unittest -v
Checks real file operations, recorded errors, directory boundaries, symlinks,
dependency validation/blocking, plan and retry previews, manual retries and
the CLI.
